# Развёртывание

Нужны Node.js 24, HTTPS reverse proxy и отдельный каталог данных. Не публикуйте Node API напрямую: он слушает `127.0.0.1:4317`.

1. Выполнить `npm ci`, `npm test`, `npm run build`.
2. Перенести `dist`, `server`, `src`, `scripts/database-snapshot.mjs`, `package.json` и lockfile. Не переносить личную `.runtime`, `.env` или локальную авторизацию.
3. На сервере установить зависимости: `npm ci --omit=dev --ignore-scripts`.
4. Задать переменные из `pole.env.example` в закрытом серверном environment file. Приложение само `.env` не читает: окружение передаёт менеджер процессов.
5. Запустить `node server/index.mjs` отдельным непривилегированным пользователем.
6. Отдавать `dist` и проксировать `/api/*` через HTTPS. Заменить домен и путь в примере Caddyfile.

`POLE_DB_PATH` должен указывать на постоянный закрытый каталог, доступный пользователю приложения. Секреты и база не должны находиться внутри статического дерева.

По умолчанию hosted-пример использует официальный API. Для другого совместимого транспорта предусмотрен `POLE_TUTOR_PROVIDER=cliproxy`, `CLIPROXY_BASE_URL=http://127.0.0.1:8317/v1`, `CLIPROXY_API_KEY` и `OPENAI_MODEL`; URL допускает только loopback. Авторизация, условия использования и обслуживание этого транспорта — отдельная задача владельца установки.

## Приёмка

Проверить сертификат HTTPS, загрузку шрифтов и интерфейса, настоящий ответ модели, восстановление после перезапуска. Два отдельных профиля браузера должны иметь разные работы. Чужой workId возвращает 404; несовпавшая сессия — 409. Один профиль браузера означает одного посетителя, а не отдельную подтверждённую личность.

Демонстрация допускает до 50 сессий по умолчанию. Истёкшие сессии не удаляются автоматически. Есть дневной бюджет модельных запросов и один одновременный вызов; при занятости интерфейс сообщает об ошибке, скрытой очереди нет.

## Резервная копия

```sh
node scripts/database-snapshot.mjs backup /var/lib/pole/state.sqlite /private-backups/new.sqlite
```

Online backup учитывает WAL, проверяет целостность и не перезаписывает существующий файл. Для восстановления остановить приложение, использовать `restore` в новый путь и переключить `POLE_DB_PATH`. Резервная копия содержит приватные работы; ограничьте доступ к ней.
