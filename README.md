## Идея продукта

Хочется сделать тренажёр, который помогает ученику продолжить именно своё решение. Сначала собственная попытка, затем конкретное наблюдение о трудном месте, короткое объяснение или проба, возврат в ту же запись, исправление и новый вариант самостоятельно. Ответ ИИ здесь — помощь в рассуждении, а не выданный за ученика результат. По тону — друг, который шарит в математике и может объяснить непонятный переход без длинной лекции.

Реализованный маршрут уже связывает материалы, варианты задач, запись с формулами, самостоятельную работу и объяснимые рекомендации следующего занятия. Направление развития — точнее различать ошибку, случайную описку и непривычный ввод, постепенно убирать помощь при самостоятельном успехе и давать полезную обратную связь по шагам. Следующий шаг проверки продуктовой гипотезы — предметная оценка преподавателями и ученический пилот; эффект на обучение пока не измерен.

Вместо обещания «ИИ проверит любое доказательство» хочется сохранять честную границу: точный checker подтверждает только поддерживаемую математическую форму, а комментарий модели к рассуждению остаётся отдельным советом. Авторские семейства затрагивают позиции экзамена; это не заявление о полном покрытии всех разновидностей и не прогноз балла.

## Быстрый запуск

Нужен Node.js 24 (в исходном проекте использовался 24.15.0) и npm. SQLite встроен в Node, отдельный сервер базы не нужен. Сначала распаковать пакет в отдельный каталог; не запускать поверх существующей базы проекта.

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173/. `npm run dev` выполняет подготовку шрифтов MathLive из установленной зависимости и запускает frontend и backend на loopback (5173 и 4317). `#home` открывает прежнюю тетрадь; без фрагмента открывается новый экзаменационный маршрут. Данные создаются локально в `.runtime/`; исходный пакет их не содержит. Остановка — Ctrl+C в терминале.

По умолчанию локальный наставник использует **собственный** установленный Codex CLI и **собственный** вход получателя. Установка или вход этим пакетом не выполняются. Если CLI/вход отсутствует, наставник сообщит о недоступности; материалы, запись и точные проверки не требуют модельного ответа. Авторизация владельца демо не передаётся и не даёт получателю доступа к провайдеру.

Для собственного OpenAI API можно задать переменные в серверном терминале перед запуском:

```powershell
$env:POLE_TUTOR_PROVIDER='openai'
$env:OPENAI_API_KEY='YOUR_API_KEY'
$env:OPENAI_MODEL='YOUR_AVAILABLE_MODEL_ID'
npm run dev
```

Заменить заглушки своими значениями. Настоящие ключи не публиковать, не добавлять в frontend или Git. `runtime.env.example` — справка по переменным; приложение не загружает этот файл автоматически. В hosted-режиме нужны отдельная БД, точный HTTPS origin и собственная серверная конфигурация. Пакет не является готовой инструкцией промышленного размещения; loopback-разработка не проверяет cookie/TLS/reverse proxy в интернете. Фото требует провайдера Responses с поддержкой изображений; локальный Codex-адаптер работает только с текстом.

## Устройство кода

| Область | Назначение |
| --- | --- |
| `src/main.tsx`, `src/components/ExamTrainer.tsx` | React/Vite, новый маршрут, выбор задач, запись, помощь, варианты и результаты |
| `src/App.tsx`, `src/editor/` | Прежняя тетрадь Tiptap/MathLive, формулы, цитаты, чат и подготовка |
| `server/index.mjs`, `server/config.mjs` | HTTP API, проверка origin, версии записей, лимиты и соединение с провайдером |
| `server/exam/` | Registry семейств, frozen instances, попытки, режим помощи, mixed/full sessions и учебные наблюдения |
| `server/store.mjs`, `server/visitors.mjs` | SQLite, данные работ и разделение браузерных профилей при размещении |
| `server/root-checker.mjs`, `server/series.mjs`, `server/exam/rational-oracle.mjs` | Поддерживаемые точные проверки; неизвестная форма не считается доказанной |
| `shared/` | Общие модели шагов, учебных наблюдений и материалов; нужны серверу и клиенту |
| `server/*adapter.mjs`, `server/photo-provider.mjs` | Изолированный текстовый Codex и Responses API; секреты только на сервере |
| `scripts/prepare-assets.mjs` | Шрифты из npm-пакета MathLive; внешние приватные assets не нужны |
| `scripts/database-snapshot.mjs` | Штатная согласованная SQLite backup/restore; не копировать один активный main-файл |

Основные границы данных: результат относится к конкретной сохранённой версии записи; помощь сохраняет самостоятельную попытку; новая вкладка/конфликт не должны молча перезаписывать работу. Фото и архив профиля содержат приватные данные, поэтому не предназначены для публикации. Локальный режим — рабочее место одного владельца; hosted-режим разделяет браузерные профили, но не подтверждает личность ученика.
