# MathMaxing

Математическая тетрадь и тренажёр для подготовки к профильному ЕГЭ. Материалы, задачи, запись с формулами и AI-наставник собраны в одном месте — чтобы разбираться в решении, а не просто получать готовый ответ.

**[Попробовать MathMaxing →](https://myvibes.space/mathmaxing/)**

## Сначала своё решение. Потом — помощь в нужном месте

Ученик начинает решать задачу сам. Если застрял, может спросить о конкретном переходе в своей записи: почему здесь появился минус, откуда взялось ограничение, что попробовать дальше.

После объяснения он возвращается в ту же тетрадь, исправляет решение и пробует новый вариант самостоятельно. Наставник остаётся рядом, а работа — у ученика.

## Что внутри

- **Материалы по темам** — объяснения и опоры рядом с практикой.
- **Задачи и варианты ЕГЭ** — отдельные упражнения, смешанная практика и экзаменационный режим.
- **Тетрадь с формулами** — математическая запись, выделение фрагмента и вопрос по своему решению.
- **Контекстная AI-помощь** — обсуждение конкретного затруднения с возвращением к собственной работе.
- **Самостоятельный режим** — новые варианты для попытки без подсказок.
- **Сохранение занятий** — записи, попытки и маршрут практики можно продолжить позже.

## Куда развивается проект

В сторону адаптивной практики: замечать конкретный пробел, подбирать короткое объяснение или упражнение и постепенно убирать помощь, когда ученик справляется сам. Следующий шаг — проверять эти сценарии вместе с преподавателями и учениками.

## Технологии

**React · TypeScript · Vite · Tiptap · MathLive · Node.js · SQLite**

Интерфейс отвечает за занятия и математическую запись. Сервер хранит работы, проверяет поддерживаемые ответы и подключает наставника. Для AI можно использовать собственный Codex CLI или OpenAI API.

## Локальный запуск

Нужны **Node.js 24** и npm. Отдельный сервер базы данных не требуется.

```powershell
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173/**. Команда запускает интерфейс и локальный сервер; данные сохраняются в `.runtime/`. Остановка — `Ctrl+C`.

По умолчанию наставник использует установленный на вашем компьютере Codex CLI с вашим входом. Если он не подключён, можно работать с материалами, тетрадью и встроенными проверками.

Чтобы подключить собственный OpenAI API, задайте переменные в серверном терминале перед запуском:

```powershell
$env:POLE_TUTOR_PROVIDER='openai'
$env:OPENAI_API_KEY='YOUR_API_KEY'
$env:OPENAI_MODEL='YOUR_AVAILABLE_MODEL_ID'
npm run dev
```

`runtime.env.example` содержит остальные настройки. Он служит справочником и не загружается автоматически. Ключи задаются на сервере и не должны попадать в клиентский код или Git. Разбор фото требует модели с поддержкой изображений; локальный Codex-адаптер работает с текстом.

## Навигация по коду

| Каталог | Что в нём |
| --- | --- |
| `src/components/`, `src/editor/` | Учебный интерфейс, тетрадь и редактор формул |
| `server/exam/` | Задачи, варианты, попытки и логика занятий |
| `server/` | API, сохранение работ, математические проверки и подключение AI |
| `shared/` | Общие данные и модели для клиента и сервера |
| `scripts/` | Подготовка ресурсов, диагностика и резервное копирование базы |

## Разработка

```powershell
npm test
npm run build
node scripts/probe-codex.mjs --self-test
```

Последняя команда проверяет адаптер на тестовых данных и не обращается к модели. Для размещения на сервере понадобятся отдельная конфигурация базы, HTTPS и настройки доступа — локальный запуск использует loopback.

Автопроверка работает с поддерживаемыми типами ответов. Подсказки AI помогают разбирать ход решения; для проверки развёрнутого доказательства по-прежнему нужен внимательный разбор.
